# 6. Temporal analysis pipeline
In this document, we describe the steps required to perform a temporal analysis using tracking.

## 6.1 Pipeline documentation
The pipeline requires running specific scripts in a specific order. Please refer to the appropriate script documentation.

1. [Spot tracking](src/tracking/btracking.md): Track the given spots over time.
2. [Nuclei tracking](src/tracking/btracking.md): Track the given nuclei over time.

This pipeline is still under implementation and further steps should be implemented in later versions of the project. <br>
For instance this pipeline is lacking quantification of spatial and temporal displacement as well as plot creation to visualise them. <br>
Nevertheless a previous tracking pipeline for light sheet microscope can be found in the archives.
